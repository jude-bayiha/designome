# Synthesize Design DNA

Read `_shared-contract.md`, the full concept matrix, and every completed stage fragment.

## Inputs

- Source manifest and evidence index
- Completed axis-stage JSON fragments
- Concept matrix and run configuration

## Task

Merge compatible claims, keep scoped exceptions, resolve or expose conflicts, normalize concept references, and assign stable rule IDs. Promote no claim beyond its evidence. Separate canonical rules, proposals, unknowns, and implementation validation.

## Output

Produce schema-valid `design-dna.json`, `design-rules.md`, `confidence-report.md`, and `unknowns.md`. Include coverage by axis and concept, unresolved conflicts, and an acceptance checklist.

## Guardrails

- Never average contradictory sources into a false universal rule.
- Exact values remain ranges or unknown unless repeatedly evidenced.
- Do not include target-project visual conventions.
- Do not install anything; synthesis ends with reviewable artifacts.
