# Render a draft calibration board

Use this specialist stage after a structurally valid extraction draft when
signature rules remain ambiguous or calibration bounds are pending. Read
`../docs/fidelity-benchmark.md`. Use `calibration-prepare` to reuse benchmark
packets, independent repetitions, hashes and evaluation; do not install the draft.

The generator receives only its brief and dossier in a separate context. Ask for
a small representative component board, with different names, values and content,
plus one longer-content state. Exercise the evidenced anatomy and relationships;
do not add a full dashboard, product sections or unrequested page families. Record
implementation choices as proposed; missing exact CSS does not authorize status
promotion. Use a suitable authorized renderer; native targets do not require
React or Playwright.

A browser/device captures defined ready states. An independent reviewer who made
no generation opens the original source and actual target images. Compare relevant
regions for proportions, useful content area, hierarchy, density, insets, row
rhythm, type, surface tiers, relief, controls and chart encodings. Use the existing
eight benchmark aspects. Respect promotional-frame exclusions and source scale;
precise recovered fonts or CSS cannot be asserted from resemblance.

Report measured evidence separately from model observations. An ambiguous rule
becomes a proposed refinement linked to its original region, not a new source
observation. Never feed generated pixels back into the source evidence index.
Missing renderer, review, repetitions or stress evidence remains incomplete. A
failed board reveals a gap or model error; do not relax bounds, mask regions or
approve it automatically. Preserve the original draft, packets and captures; a
revised draft uses a new benchmark directory and new packet hashes.

Present the experiment and limitations before asking for human DNA acceptance.
Technical validity, a successful capture and a model verdict never accept DNA.
